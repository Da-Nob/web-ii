# Programação Web II

Repositório destinado à disciplina de **Programação Web II**, do curso de Análise e Desenvolvimento de Sistemas.

## 📚 Sobre a disciplina

A disciplina aborda conceitos e práticas relacionados ao desenvolvimento de aplicações Web, com foco principalmente no desenvolvimento **front-end**, na utilização de frameworks, na integração com o **back-end**, no desenvolvimento de aplicações multiplataforma e no consumo e manipulação de APIs.

Durante a disciplina serão desenvolvidas atividades práticas utilizando tecnologias e ferramentas voltadas para o desenvolvimento Web.

## 🎯 Objetivos

O principal objetivo da disciplina é desenvolver conhecimentos e habilidades para a criação de aplicações Web, integrando o desenvolvimento front-end com o back-end.

Entre os principais objetivos estão:

- Desenvolver interfaces Web utilizando boas práticas de desenvolvimento;
- Aprender e utilizar JavaScript no desenvolvimento de aplicações Web;
- Conhecer frameworks utilizados no desenvolvimento front-end;
- Trabalhar com componentes e comunicação entre eles;
- Desenvolver aplicações Web integradas com back-end;
- Utilizar APIs para comunicação e manipulação de dados;
- Conhecer conceitos relacionados a aplicações multiplataforma;
- Desenvolver aplicações utilizando tecnologias como PWA;
- Conhecer práticas de versionamento de código.
